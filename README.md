This project was done because we found witch trials really interesting to explore. The main question that came up for us when researching the European Witch Trials was why did this happen? There were answers of misogyny, religion, power systems, and much more complex issues, but because of the time period of this data set, there is only so much we could explore. Which is why we focused on economics and hunger, did people accuse and kill more whne they were hungry?
We did this by comparing the witch trial deaths and the number accused with the French wheat prices. Not spoil, but there is a correlation. But it's important to remember this is not the full picture; there are so many other reasons, all tied to maintaining the power structure of the patriarchy and the economic system.
In future projects we would love to mix both quantitative data of economic factors and climate (considering the Little Ice Age also played a part in the witch trials) with qualitative reasons as well. Considering misogyny, classism, and religious power. We hope you enjoy this project and are inspired to learn more about the witch trials. Thank you!
